# Fools Apprentice

Every craftsman starts as an apprentice.

This organization collects the projects I've built while working through courses, curricula and other structured learning. These are practice projects: exercises, assignments and small builds made to learn a language, framework or concept by actually doing it.

My original and professional work lives on my personal profile: [Fools Flagon Studio](https://github.com/FoolsFlagonStudio)

## Why a separate organization?

- **Clear separation:** coursework stays here, and my own projects stay on my profile, so each is easy to find.
- **A record of progress:** each repo shows where I was at that point in my learning, from early exercises to larger multi-class projects.
- **Honest context:** everything here started as an assignment from an educational source, and each repo's README links to the original assignment.
